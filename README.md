# 📖 react-portfolio-webpage

>  Learn to create and deploy a fully responsive personal portfolio website using React.js. This project covers setting up a React app, integrating React Icons, managing state with useState, designing with CSS3, and adding multiple contact options like EmailJS, WhatsApp, and Email. By the end, you'll have a modern, mobile-friendly portfolio ready for deployment on platforms like Netlify or Vercel.

### Key Features 

### Key Features:
- **Responsive Design:** Build a mobile-friendly and visually appealing website using CSS3.  
- **React Integration:** Set up a React app with React Icons and use `useState` for interactive components.   
- **Multiple Contact Options:** Enable EmailJS for form submissions, and integrate WhatsApp and Facebook Messenger.  
- **Deployment:** Host your portfolio on platforms like Netlify, Vercel, or GitHub Pages.

## 💻 Getting Started 

To get a local copy up and running, follow these steps.

### Setup

Clone this repository to your desired folder:

```sh
  git clone https://github.com/farwamuhibzada/react-portfolio-webpage
  cd react-portfolio-webpage
```

### Install

Install this project with:

```sh
  npm install
```

### Usage

To run the project in a development server, execute the following command:

```sh
  npm start
```

### Testing

To run the tests in a development server, execute the following command:

```sh
  npm test
```

To to build for the production, execute the following command:

```sh
  npm run build
```
